# 전기산업기사 강의 선택 노트

전기산업기사 온라인 강의를 고를 때 강사, 커리큘럼, 기출 해설, 실기 연계, 수강기간을 비교할 수 있도록 만든 순수 정적 정보 사이트입니다.

## GitHub Pages 정보

- Organization: `electric-industrial-course-guide`
- Repository: `electric-industrial-course-guide.github.io`
- Pages URL: `https://electric-industrial-course-guide.github.io/`

## 배포 방법

1. GitHub에서 위 Organization과 Repository를 준비합니다.
2. 이 폴더의 파일을 Repository 최상단에 업로드합니다.
3. Repository의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택합니다.
4. `main` 브랜치의 `/ (root)`를 선택해 저장합니다.
5. 배포가 완료되면 위 Pages URL에서 사이트를 확인합니다.

별도 빌드나 패키지 설치는 필요하지 않습니다.
